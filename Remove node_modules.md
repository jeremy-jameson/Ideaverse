The `node_modules` folder can use a lot of disk space because it contains a project's packages and all their dependencies. Multiply this by a large number of projects, and well…pretty soon that precious SSD might just run out of room completely! 😒

My solution? Pick a "level" to start at and then purge each and every one of them. 😂

```PowerShell
cd C:\NotBackedUp\GitHub

Get-ChildItem node_modules -Recurse -Directory |
    foreach { Remove-Item $_ -Recurse -Force -Verbose }
```
